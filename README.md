# Restro Café Idea Validation Dashboard

Streamlit dashboard for the Data Analytics for Business Strategy project (SP Jain, MGB).
It cleans a synthetic UAE customer survey and shows descriptive and diagnostic analytics, ending in a sales pipeline and break-even view for a family-focused, health-led restro café.

## Files
- `app.py`: the Streamlit app
- `cafe_survey_synthetic_data.csv`: raw synthetic survey (3,552 rows)
- `requirements.txt`: Python packages

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```

The data is simulated for coursework; it is not real customer data.
